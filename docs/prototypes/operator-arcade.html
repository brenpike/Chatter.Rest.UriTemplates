The problem

Hand-built URLs break in three places.

Concatenation looks fine until a value has a space or an ampersand, a parameter is missing, or a list needs repeating. A URI template states the shape once, and the expander gets every edge case right.

Glued string Game over

var url = "/search?q=" + q
        + "&page=" + page
        + "&tag=" + string.Join(",", tags);
/search?q=R&D tools&page=&tag=a,b
  • The & in “R&D” starts a new parameter, and the space is invalid.
  • The missing page still leaves an empty page= behind.
  • The tags collapse into one value instead of repeating.

URI template High score

var url = new UriTemplate("/search{?q,page,tag*}")
    .Expand(values);
  • Values are percent-encoded for the part of the URI they land in.
  • Undefined variables drop out, separator and all.
  • The explode modifier * repeats each list item.

Inside the cabinet

How a template becomes a URI.

Four stages, each with one job. Follow /search{?q,lang} through the machine.

1

Parse

The template is parsed once, when you construct it. A malformed template fails right there with a FormatException, never later.

"/search{?q,lang}"✓ valid
2

Tokenize

Text splits into literal tokens, copied as written, and expression tokens, which hold an operator and its variables.

literal /searchexpression {?q,lang}
3

Strategy

Each operator has its own strategy that decides the leading character, the separator and whether values carry their names.

operator ?starts ? · joins & · named
4

Encode

Values are UTF-8 percent-encoded to RFC 3986. Only + and # keep reserved characters such as / and ?.

Two cartridges

The engine, and an easy way to plug it in.

Core packageChatter.Rest.UriTemplates

The whole RFC 6570 engine: parsing, all eight operators, prefix and explode modifiers, and encoding.

  • No external dependencies
  • Targets .NET Standard 2.0 and .NET 8
var template = new UriTemplate("/orders{?status,page}");

var uri = template.Expand(new Dictionary<string, string>
{
    ["status"] = "shipped",
    ["page"] = "2"
});
// /orders?status=shipped&page=2
Dependency injectionChatter.Rest.UriTemplates.DependencyInjection

One call registers the parser and a template factory with the Microsoft dependency injection container. Inject the factory wherever you build links.

  • Adds services.AddUriTemplates()
  • Inject IUriTemplateFactory and call Create
services.AddUriTemplates();

public class OrderLinks(IUriTemplateFactory templates)
{
    public string Page(string page) =>
        templates.Create("/orders{?page}")
                 .Expand(("page", page));
}
