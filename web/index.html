RFC 6570 URI Templates for .NET

Write the shape of a URL once. Let the values fill it in.

Chatter.Rest.UriTemplates turns a template like the one on the stage into a correct, fully encoded URI, for every operator in the spec.

by Brennan Pike

Scroll to watch one template expand

The problem

URLs built by hand break quietly.

Gluing strings together looks harmless. The compiler is happy, and the first test with plain ASCII passes.

Then real data shows up. An accented city name, a search with an ampersand in it, a list nobody agreed how to format. The URL still gets sent. It just means something else.

Every caller ends up re-solving encoding, separators and optional parts, and solving them slightly differently.

The answer

A standard for describing URLs: RFC 6570.

A URI template is a URL with holes in it. Each hole is an expression in braces. The expression says which variables go there and, through its operator, how they should be joined and encoded.

The spec grows in four levels. Level 1 substitutes a single value. Level 4 handles lists, maps, prefixes and exploded values. This library implements all four.

Watch it expand

The braces open.

Each expression's operator decides what comes before its values. The / in {/city} means "a path segment". The ? in {?q,diet*} means "start a query string, with names".

The values arrive.

Two strings and a list. The * on diet explodes the list, so each item gets its own diet= pair instead of one comma-joined value.

Every unsafe character is encoded.

Non-ASCII letters become their UTF-8 bytes. Spaces become %20. The ampersand inside the search becomes %26, so it can no longer pose as a parameter separator.

Which characters count as unsafe depends on the operator. Query and path expressions encode everything outside the unreserved set. {+path} and {#path} let reserved characters through.

One string. Correct every time.

var uri = new UriTemplate("/menus{/city}/search{?q,diet*}")
    .Expand(new Dictionary<string, UriTemplateValue>
    {
        ["city"] = UriTemplateValue.From("Montréal"),
        ["q"]    = UriTemplateValue.From("café & crêpes"),
        ["diet"] = UriTemplateValue.From(new[] { "vegan", "gluten-free" })
    });

The template is the contract. The values change; the rules for joining and encoding them never do.

The vocabulary

Eight operators cover every part of a URL.

The first character inside the braces picks the operator. Each one knows its prefix, its separator, whether it names values, and which characters it allows through.

OpUseTemplateResult
noneSimple string{x,y}1024,768
+Reserved{+path}/here/foo/bar/here
#Fragment{#path}#/foo/bar
.Label{.x,y}.1024.768
/Path segments{/list*}/red/green/blue
;Path parameters{;x,y};x=1024;y=768
?Query{?x,y}?x=1024&y=768
&Query continuation?fixed=yes{&x}?fixed=yes&x=1024

Modifiers shape the values.

A value can be a string, a list, or a map of names to values. Two modifiers change how it lands. :N keeps only the first N characters of a string. * explodes a list or map into separate parts.

The two can't be combined on one variable; the parser rejects that. Map keys are sorted, so the same map always expands to the same URI.

How it works

Parsed up front. Mistakes fail fast.

The template is parsed when you construct it, not when you expand it. An unclosed or nested brace, an empty expression or a doubled operator throws a FormatException straight away, long before a request is made.

Text and expressions become tokens.

The parser splits the template into literal tokens and expression tokens. Literal text is checked and encoded too, so stray characters can't slip into the result.

Each operator gets its own strategy.

Expansion hands every expression to the strategy for its operator. One small class per rule set keeps each operator's behavior in one place.

Encoding follows RFC 3986.

Values are encoded as UTF-8 with the character set the operator allows. Undefined variables simply drop out, along with their separators.

Out comes the URI.

Parse once, expand as often as you like. The template object holds no per-call state, so one instance can serve every request.

public sealed class MenuClient(IUriTemplateFactory templates)
{
    private readonly UriTemplate _search =
        templates.Create("/menus{/city}/search{?q,diet*}");
}

Get started

One package. One line.

Add the package and expand your first template. Strings, lists, dictionaries and every operator work the same way.

Install

dotnet add package Chatter.Rest.UriTemplates

Using dependency injection too? Add Chatter.Rest.UriTemplates.DependencyInjection.

First expansion

using Chatter.Rest.UriTemplates;

var template = new UriTemplate("/orders{?status,page}");

var uri = template.Expand(new Dictionary<string, string>
{
    ["status"] = "shipped",
    ["page"] = "2"
});
// "/orders?status=shipped&page=2"
